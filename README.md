# Aesthetic LeetCode

Aesthetic Puzzles turns classic puzzles and brain teasers into visual, interactive, and beginner-friendly learning experiences.
https://shelvia-w.github.io/aesthetic-puzzles/

![Alt](https://repobeats.axiom.co/api/embed/251e45a8a486428ba01a1cd6d949675b1a2b59e3.svg "Repobeats analytics image")

Features:
- **Pattern-based learning**: organize problems by concepts like two pointers, sliding window, and more.
- **Interactive visualizers**: explore algorithm steps through hands-on animations.
- **Problem walkthroughs**: understand the intuition, approach, and solution clearly.
- **Aesthetic infographics**: learn key ideas through visually memorable summaries.
- **Beginner-friendly design**: make LeetCode practice feel less intimidating and more enjoyable.
